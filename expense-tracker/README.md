# Smart Expense Tracker API

A small REST API for tracking personal expenses, built with FastAPI. Data is
stored in memory and persisted to a local JSON file (`expenses.json`), so no
database is required.

## Features

- Add an expense (title, amount, category, date)
- List all expenses
- Filter expenses by category
- Get a single expense by id
- Delete an expense
- Totals: overall total and total broken down by category
- **Bonus:** search expenses by title (`GET /expenses/search?q=...`)
- Interactive API docs at `/docs` (Swagger UI, auto-generated by FastAPI)

## Requirements

- Python 3.10+

## Install

```bash
python3 -m venv venv
source venv/bin/activate        # on Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run the server

```bash
uvicorn src.main:app --reload
```

The API will be available at `http://127.0.0.1:8000`.
Interactive docs: `http://127.0.0.1:8000/docs`.

## Run the tests

```bash
pytest
```

Tests use a temporary data file per test run (via a fixture in
`tests/test_api.py`), so running them never touches or overwrites your real
`expenses.json`.

## API Reference

| Method | Path                        | Description                              |
|--------|-----------------------------|-------------------------------------------|
| POST   | `/expenses`                 | Add an expense                           |
| GET    | `/expenses`                 | List all expenses (optional `?category=`)|
| GET    | `/expenses/search?q=`       | Search expenses by title (bonus)         |
| GET    | `/expenses/{id}`            | Get a single expense                     |
| DELETE | `/expenses/{id}`            | Delete an expense                        |
| GET    | `/expenses/totals/summary`  | Overall total + total by category        |

### Example: add an expense

```bash
curl -X POST http://127.0.0.1:8000/expenses \
  -H "Content-Type: application/json" \
  -d '{"title": "Coffee", "amount": 4.5, "category": "Food", "date": "2026-01-15"}'
```

### Example: filter by category

```bash
curl "http://127.0.0.1:8000/expenses?category=Food"
```

### Example: totals

```bash
curl http://127.0.0.1:8000/expenses/totals/summary
```

## Design notes

- **Validation:** `amount` must be a positive number; `title` and `category`
  must not be blank. Invalid input returns `422` with details.
- **Persistence:** every write (add/delete) rewrites `expenses.json` so data
  survives a server restart. It's simple file-based persistence, not meant
  for concurrent multi-process use.
- **Category filtering** is case-insensitive.
- **IDs** are auto-incrementing integers assigned by the server.
